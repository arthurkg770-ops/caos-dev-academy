PYTHON — AULA 01

Variáveis

Uma variável é como uma pequena caixa onde podemos guardar uma informação. 

nome = "Arthur"
idade = 13
xp = 100

print(nome)
print(idade)
print(xp)

O símbolo = serve para colocar um valor dentro da variável.

🎯 Desafio

Qual comando usamos em Python para mostrar uma informação na tela?

PYTHON POO — AULA 01

Classes e Objetos

Uma classe funciona como um molde. Os objetos são criados a partir desse molde. 

class Jogador:

    def __init__(self, nome):
        self.nome = nome
        self.vida = 100


jogador = Jogador("Arthur")

print(jogador.nome)
print(jogador.vida)

A classe define como o objeto será. O objeto é uma instância dessa classe.

Qual palavra usamos para criar uma classe em Python?
