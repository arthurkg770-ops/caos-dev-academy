# ⚔️ CAOS DEV ACADEMY

> Minha plataforma pessoal para aprender programação, desenvolvimento e tecnologia.

## 🚀 Sobre o projeto

A **CAOS DEV ACADEMY** é uma plataforma de estudos criada para acompanhar minha evolução como desenvolvedor.

A ideia é transformar o aprendizado em uma experiência com:

* 📚 Cursos e aulas
* 🧠 Exercícios práticos
* 🎯 Desafios
* ⭐ Sistema de XP
* 🆙 Sistema de níveis
* 📊 Progresso de estudos
* 🏆 Conquistas
* 💻 Projetos práticos
* 🔐 CyberSecurity
* 🌐 Desenvolvimento Web
* 🐍 Python
* 🗄️ Banco de Dados
* 🐧 Linux
* 🌐 Redes

## 🛠️ Tecnologias

Atualmente o projeto utiliza:

* HTML
* CSS
* JavaScript
* Git
* GitHub Pages

## 🎓 Trilha de aprendizado

A Academy será construída e expandida conforme meu conhecimento evolui.

### 🐍 Python

Fundamentos, lógica, funções, POO, projetos e Python profissional.

### 💻 Desenvolvimento

Git, GitHub, organização de projetos, código limpo e ferramentas profissionais.

### 🌐 Web

HTML, CSS, JavaScript, interfaces e aplicações web.

### 🗄️ Database

SQL, bancos de dados, tabelas, relacionamentos e persistência.

### 🐧 Linux

Terminal, arquivos, processos, permissões e servidores.

### 🌐 Redes

IP, DNS, HTTP, TCP, UDP, portas e protocolos.

### 🔐 CyberSecurity

Fundamentos de segurança, defesa, vulnerabilidades e proteção de sistemas.

### 🥷 Ethical Hacking

Pentest e segurança ofensiva em ambientes próprios ou autorizados.
