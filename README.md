📚 Sobre o projeto

A CAOS DEV ACADEMY é uma plataforma de estudos desenvolvida para organizar e acompanhar a evolução em programação, desenvolvimento, infraestrutura e cibersegurança.

O projeto foi pensado para funcionar como uma verdadeira central de aprendizado, reunindo:

Aprender → Praticar → Experimentar → Construir

🎯 Objetivo

O objetivo da CAOS DEV ACADEMY é oferecer um ambiente onde o estudante possa:

Aprender conceitos.

Praticar através de exercícios.

Experimentar em laboratórios.

Resolver desafios.

Construir projetos.

Acompanhar o próprio progresso.

Revisar conteúdos quando necessário.

Em vez de apenas consumir conteúdo, a plataforma incentiva a aplicação prática do conhecimento.

▶️ Como executar

Localmente

Baixe o projeto e abra:

index.html

O navegador executará a aplicação diretamente.

GitHub Pages

Crie ou abra um repositório no GitHub.

Envie o index.html.

Vá até Settings → Pages.

Selecione a branch principal.

Escolha a pasta /root.

Salve.

Aguarde a publicação.

Depois disso, a plataforma poderá ser acessada através do endereço gerado pelo GitHub Pages.
